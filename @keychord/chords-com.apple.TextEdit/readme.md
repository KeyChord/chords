# @keychord/chords-com.apple.TextEdit

Chords for TextEdit (`com.apple.TextEdit`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/TextEdit/macos.toml).

Build with `vp pack` and run `vp run test` for Bun tests. From the monorepo root,
run `CHORD_TESTING_VM_NAME=chords-testing-golden-gate node_modules/.bin/chordtest test @keychord/chords-com.apple.TextEdit` for the macOS 27 VM tests.
