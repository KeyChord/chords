# @keychord/chords-com.apple.mobilephone

Chords for Phone (`com.apple.mobilephone`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/mobilephone/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.mobilephone` from the monorepo root for VM tests.
