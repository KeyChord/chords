# @keychord/chords-com.apple.DVDPlayer

Chords for DVD Player (`com.apple.DVDPlayer`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/DVDPlayer/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.DVDPlayer` from the monorepo root for VM tests.
