# @keychord/chords-com.apple.DiskUtility

Chords for Disk Utility (`com.apple.DiskUtility`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/DiskUtility/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.DiskUtility` from the monorepo root for VM tests.
