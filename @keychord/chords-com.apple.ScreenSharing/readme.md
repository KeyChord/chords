# @keychord/chords-com.apple.ScreenSharing

> [!WARNING]
> **EXPERIMENTAL**
>
> This package was largely created with AI and will be reviewed by a human later.

Chords for Screen Sharing (`com.apple.ScreenSharing`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/ScreenSharing/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.ScreenSharing` from the monorepo root for VM tests.
