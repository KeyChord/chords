# @keychord/chords-com.apple.games

Chords for Games (`com.apple.games`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/games/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.games` from the monorepo root for VM tests.
