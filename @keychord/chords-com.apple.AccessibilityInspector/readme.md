# @keychord/chords-com.apple.AccessibilityInspector

Chords for Accessibility Inspector (`com.apple.AccessibilityInspector`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/AccessibilityInspector/macos.toml) and [global bindings](./chords/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.AccessibilityInspector` from the monorepo root for VM tests.
