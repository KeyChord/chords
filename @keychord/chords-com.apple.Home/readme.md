# @keychord/chords-com.apple.Home

Chords for Home (`com.apple.Home`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Home/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Home` from the monorepo root for VM tests.
