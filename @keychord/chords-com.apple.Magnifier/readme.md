# @keychord/chords-com.apple.Magnifier

Chords for Magnifier (`com.apple.Magnifier`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Magnifier/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Magnifier` from the monorepo root for VM tests.
