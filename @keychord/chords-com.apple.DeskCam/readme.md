# @keychord/chords-com.apple.DeskCam

Chords for Desk View (`com.apple.DeskCam`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/DeskCam/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.DeskCam` from the monorepo root for VM tests.
