# @keychord/chords-com.apple.MigrateAssistant

> [!WARNING]
> **EXPERIMENTAL**
>
> This package was largely created with AI and will be reviewed by a human later.

Chords for Migration Assistant (`com.apple.MigrateAssistant`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/MigrateAssistant/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.MigrateAssistant` from the monorepo root for VM tests.
