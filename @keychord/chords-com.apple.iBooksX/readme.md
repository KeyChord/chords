# @keychord/chords-com.apple.iBooksX

Chords for Books (`com.apple.iBooksX`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/iBooksX/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.iBooksX` from the monorepo root for VM tests.
