# @keychord/chords-com.apple.DigitalColorMeter

Chords for Digital Color Meter (`com.apple.DigitalColorMeter`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/DigitalColorMeter/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.DigitalColorMeter` from the monorepo root for VM tests.
