# @keychord/chords-com.apple.stocks

Chords for Stocks (`com.apple.stocks`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com.apple.stocks/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.stocks` from the monorepo root for VM tests.
