# @keychord/chords-com.apple.freeform

Chords for Freeform (`com.apple.freeform`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/freeform/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.freeform` from the monorepo root for VM tests.
