# @keychord/chords-com.apple.GenerativePlaygroundApp

Chords for Image Playground (`com.apple.GenerativePlaygroundApp`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/GenerativePlaygroundApp/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.GenerativePlaygroundApp` from the monorepo root for VM tests.
