# @keychord/chords-com.apple.MobileSMS

Chords for Messages (`com.apple.MobileSMS`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/MobileSMS/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.MobileSMS` from the monorepo root for VM tests.
