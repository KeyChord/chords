# @keychord/chords-com.apple.iCal

Chords for Calendar (`com.apple.iCal`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/iCal/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.iCal` from the monorepo root for VM tests.
