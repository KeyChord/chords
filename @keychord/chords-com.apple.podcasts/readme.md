# @keychord/chords-com.apple.podcasts

Chords for Podcasts (`com.apple.podcasts`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/podcasts/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.podcasts` from the monorepo root for VM tests.
