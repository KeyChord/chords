# @keychord/chords-com.apple.FaceTime

Chords for FaceTime (`com.apple.FaceTime`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/FaceTime/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.FaceTime` from the monorepo root for VM tests.
