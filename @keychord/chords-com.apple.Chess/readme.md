# @keychord/chords-com.apple.Chess

Chords for Chess (`com.apple.Chess`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Chess/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Chess` from the monorepo root for VM tests.
