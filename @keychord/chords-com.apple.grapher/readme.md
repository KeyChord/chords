# @keychord/chords-com.apple.grapher

Chords for Grapher (`com.apple.grapher`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/grapher/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.grapher` from the monorepo root for VM tests.
