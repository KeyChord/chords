# @keychord/chords-com.apple.VoiceOverUtility

> [!WARNING]
> **EXPERIMENTAL**
>
> This package was largely created with AI and will be reviewed by a human later.

Chords for VoiceOver Utility (`com.apple.VoiceOverUtility`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/VoiceOverUtility/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.VoiceOverUtility` from the monorepo root for VM tests.
