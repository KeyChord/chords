# @keychord/chords-com.apple.helpviewer

Chords for Tips (`com.apple.helpviewer`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com.apple.helpviewer/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.helpviewer` from the monorepo root for VM tests.
