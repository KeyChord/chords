# @keychord/chords-com.apple.clock

Chords for Clock (`com.apple.clock`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/clock/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.clock` from the monorepo root for VM tests.
