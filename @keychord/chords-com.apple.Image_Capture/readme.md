# @keychord/chords-com.apple.Image_Capture

Chords for Image Capture (`com.apple.Image_Capture`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Image_Capture/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Image_Capture` from the monorepo root for VM tests.
