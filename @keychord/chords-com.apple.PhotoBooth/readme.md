# @keychord/chords-com.apple.PhotoBooth

Chords for Photo Booth (`com.apple.PhotoBooth`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/PhotoBooth/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.PhotoBooth` from the monorepo root for VM tests.
