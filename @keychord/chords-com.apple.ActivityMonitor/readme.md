# @keychord/chords-com.apple.ActivityMonitor

Chords for Activity Monitor (`com.apple.ActivityMonitor`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/ActivityMonitor/macos.toml) and [global bindings](./chords/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.ActivityMonitor` from the monorepo root for VM tests.
