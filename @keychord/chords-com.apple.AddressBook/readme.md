# @keychord/chords-com.apple.AddressBook

Chords for Contacts (`com.apple.AddressBook`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/AddressBook/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.AddressBook` from the monorepo root for VM tests.
