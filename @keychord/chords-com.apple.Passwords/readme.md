# @keychord/chords-com.apple.Passwords

Chords for Passwords (`com.apple.Passwords`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Passwords/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Passwords` from the monorepo root for VM tests.
