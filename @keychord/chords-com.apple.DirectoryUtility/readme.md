# @keychord/chords-com.apple.DirectoryUtility

Chords for Directory Utility (`com.apple.DirectoryUtility`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/DirectoryUtility/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.DirectoryUtility` from the monorepo root for VM tests.
