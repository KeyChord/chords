# @keychord/chords-com.apple.Notes

Chords for Notes (`com.apple.Notes`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Notes/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Notes` from the monorepo root for VM tests.
