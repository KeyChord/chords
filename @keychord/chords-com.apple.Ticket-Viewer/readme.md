# @keychord/chords-com.apple.Ticket-Viewer

Chords for Ticket Viewer (`com.apple.Ticket-Viewer`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Ticket-Viewer/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Ticket-Viewer` from the monorepo root for VM tests.
