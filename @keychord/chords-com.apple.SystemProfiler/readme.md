# @keychord/chords-com.apple.SystemProfiler

Chords for System Information (`com.apple.SystemProfiler`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/SystemProfiler/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.SystemProfiler` from the monorepo root for VM tests.
