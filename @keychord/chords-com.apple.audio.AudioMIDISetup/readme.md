# @keychord/chords-com.apple.audio.AudioMIDISetup

Chords for Audio MIDI Setup (`com.apple.audio.AudioMIDISetup`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/audio/AudioMIDISetup/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.audio.AudioMIDISetup` from the monorepo root for VM tests.
