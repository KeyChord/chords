# @keychord/chords-com.apple.Photos

Chords for Photos (`com.apple.Photos`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Photos/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Photos` from the monorepo root for VM tests.
