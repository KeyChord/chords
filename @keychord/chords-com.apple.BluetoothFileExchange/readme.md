# @keychord/chords-com.apple.BluetoothFileExchange

> [!WARNING]
> **EXPERIMENTAL**
>
> This package was largely created with AI and will be reviewed by a human later.

Chords for Bluetooth File Exchange (`com.apple.BluetoothFileExchange`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/BluetoothFileExchange/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.BluetoothFileExchange` from the monorepo root for VM tests.
