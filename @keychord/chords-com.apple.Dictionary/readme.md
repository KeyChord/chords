# @keychord/chords-com.apple.Dictionary

Chords for Dictionary (`com.apple.Dictionary`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com.apple.Dictionary/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Dictionary` from the monorepo root for VM tests.
