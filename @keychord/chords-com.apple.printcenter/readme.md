# @keychord/chords-com.apple.printcenter

Chords for Print Center (`com.apple.printcenter`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/printcenter/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.printcenter` from the monorepo root for VM tests.
