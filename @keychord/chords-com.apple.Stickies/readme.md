# @keychord/chords-com.apple.Stickies

> [!WARNING]
> **EXPERIMENTAL**
>
> This package was largely created with AI and will be reviewed by a human later.

Chords for Stickies (`com.apple.Stickies`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Stickies/macos.toml).

Build with `vp pack` and run `vp run test` for Bun tests. From the monorepo root,
run `CHORD_TESTING_VM_NAME=chords-testing-golden-gate node_modules/.bin/chordtest test @keychord/chords-com.apple.Stickies` for the macOS 27 VM tests.
