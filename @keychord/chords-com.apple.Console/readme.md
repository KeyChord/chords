# @keychord/chords-com.apple.Console

Chords for Console (`com.apple.Console`). Install through the
`KeyChord/chords` monorepo and enable this package under Settings → Chords.

[App bindings](./chords/com/apple/Console/macos.toml).

Build with `vp pack`. Run `vp run test` for Bun tests or
`vp run test:macos -- @keychord/chords-com.apple.Console` from the monorepo root for VM tests.
